Software Engineer with **20+ years of experience**, mostly in **Java and Spring**. I work across the stack, from **legacy enterprise systems** (Java EE, EJB, JSF, WebLogic) to **modern microservices**, REST APIs, messaging and cloud platforms.
 
Over the last few years I've been working remotely as a contractor for Canadian companies, where I design features and architecture, mentor developers and push for solid testing and code review. I also build side projects end to end, from backend to mobile, and I use AI-assisted development daily for implementation, debugging and refactoring.
